FEATURES

One node,
the whole suite.

  • Everything the Patrol has. The same battery-powered netTAK mesh node with GPS timing and external-antenna options — see the Patrol build.
  • Dual-USB expansion. Two panel-mounted USB ports bring accessories to the outside of the case, so you can add and swap modules in the field.
  • Overwatch & sensing. Add surveillance cameras and mmWave presence detection to turn a node into a silent sentry on your ATAK map.
  • digiTAK on the air. A digirig bridges an amateur radio for VHF/UHF data — run digiTAK straight from the node.
  • sdrTAK overhead. An RTL-SDR pulls aircraft (ADS-B) and ships (AIS) off the air — run sdrTAK on the same node.
  • loraTAK mesh. A Meshtastic radio adds long-range LoRa — run loraTAK alongside the HaLow mesh.
  • Passive cooling. A heatsink built into the printed case pulls heat off the Pi — no fan, nothing to fail, silent in the field.
  • Forward-site ready. Built to sit in a case at a fixed site and serve a whole team's EUDs.
