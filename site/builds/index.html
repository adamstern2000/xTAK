xTAK / Builds

Build your
own node.

Every xTAK product runs on a carry-anywhere appliance you can build yourself. These are our reference hardware builds — the exact nodes we run, with full parts lists, substitution notes, and step-by-step build guides. Pick the node that fits the mission, source the parts, and put a self-contained TAK network in a case.

Basecamp

Largest · site / whole-suite

The do-everything node. Dual-USB expansion drives cameras, mmWave sensing, and the digiTAK, sdrTAK & loraTAK radios — one box runs the whole suite.

netTAK MeshdigiTAKsdrTAKloraTAKmbtileserver
View the build
New to these builds? Patrol and Basecamp run on a Raspberry Pi 4B, the Scout on a smaller Pi Zero 2 W — each in a field case running the xTAK software you license. The one part we sell directly is the Wi-Fi HaLow radio (Vantron VT-USB-AH-8108), required only for netTAK Mesh — everything else is off-the-shelf and linked in each build's parts list.

What runs
where.

Every build runs netTAK Standalone and mbtileserver out of the box. Beyond that, each node runs the packages below — just add the small plug-in device each one needs.

Scout
digiTAK · digirig
Patrol
netTAK Mesh · HaLow
Basecamp
netTAK Mesh · HaLow digiTAK · digirig sdrTAK · RTL-SDR loraTAK · Meshtastic

Scout is the digiTAK node, Patrol the netTAK Mesh node, and Basecamp runs all four — on their own or several at once.
