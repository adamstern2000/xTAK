digiTAK — APRS Icons Installation Guide (ATAK & WinTAK)

digiTAK bridges APRS stations onto your TAK map. Out of the box, TAK draws them with generic markers. This one-time install adds the APRS symbol set — the same primary/secondary symbols used across the APRS world (Hessu Hannikainen's set, 188 icons) — so a weather station looks like a weather station, a vehicle like a vehicle, a digipeater like a digipeater, and so on, on ATAK and WinTAK.

Once installed, digiTAK's markers resolve automatically: every APRS object digiTAK emits carries its icon reference, and TAK renders the matching symbol. No per-marker work — you just install the iconsets once per device.

You install TWO iconsets — one for each APRS symbol table:

File Iconset Symbol table Icons
APRSPrimary.zip APRSPrimary primary (/) 94
APRSSecondary.zip APRSSecondary secondary (\) 94

Install both. With only one, half of APRS symbols won't resolve.

What you need

  • APRSPrimary.zip and APRSSecondary.zip — download both from the xTAK download page (they ship with digiTAK, and are attached to the digiTAK release).
  • The TAK client you're setting up:
  • WinTAK on a Windows machine, or
  • ATAK on an Android device.
  • A way to get the two zips onto the device:
  • WinTAK: copy them to any folder on the Windows machine.
  • ATAK: copy them to the Android device (USB cable, or a Wi-Fi transfer app like LocalSend). Put them somewhere you can browse to, e.g. Download/.

Install the icons on every ATAK/WinTAK device that connects to digiTAK.

Part 1 · WinTAK

  1. Open WinTAK.
  2. Open the Point Dropper tool, then click its Settings (the gear icon).
  3. Open the Iconset Manager.
  4. Click [ + ] (add) → browse to APRSPrimary.zip → open. WinTAK imports it.
  5. Click [ + ] again → select APRSSecondary.zip → open.
  6. Confirm both APRSPrimary and APRSSecondary now appear in the iconset list.

That's it — WinTAK now resolves digiTAK's APRS symbols.

Part 2 · ATAK (Android)

  1. Copy APRSPrimary.zip and APRSSecondary.zip onto the device (into Download/, or straight into atak/iconsets/ if you prefer — see the note).
  2. Open ATAK.
  3. Open the ≡ menu → Import Manager.
  4. Choose Local SD (import from device storage) → browse to APRSPrimary.zip → select it. ATAK imports the iconset.
  5. Repeat for APRSSecondary.zip.
  6. Verify: open the Point Dropper, tap the icon/palette selector, and confirm the APRSPrimary and APRSSecondary groups are listed.

Alternative (manual): ATAK also loads iconsets placed directly in the device's atak/iconsets/ folder. Unzip each package there so you have atak/iconsets/APRSPrimary/… and atak/iconsets/APRSSecondary/…, then restart ATAK. The Import Manager route above is easier and does this for you.

Verify (both clients)

With the client connected to digiTAK (over your netTAK Wi‑Fi or LAN), let an APRS station come in — for example a nearby weather station or a mobile tracker. On the map it should now render with its proper APRS symbol instead of a generic marker. If symbols render, you're done.

If something's not right

Symptom Fix
Some APRS markers show a generic/placeholder icon You likely installed only one table. Install both APRSPrimary and APRSSecondary.
Iconsets don't appear in the list after import Re-run the import and confirm you selected the .zip (not an extracted folder) via the Iconset Manager (WinTAK) / Import Manager (ATAK).
WinTAK refuses to import the zip Use the zips exactly as distributed — do not re-zip them. WinTAK's importer rejects zips repacked by some tools. Re-download the originals.
ATAK: icons still generic after import Fully close and reopen ATAK so it reloads iconsets, then re-check the Point Dropper icon selector.
