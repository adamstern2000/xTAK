netTAK Voice
Install Guide.

netTAK product netTAK install guide Your downloads

netTAK Voice turns a Raspberry Pi with a Codec Zero audio HAT into a push-to-talk (PTT) radio endpoint on the netTAK network. It speaks the same Opus-over-multicast voice channels as ATAK's VX plugin, so a handset with a PTT button talks to phones/tablets running VX — with no server and no internet.

The voice engine (nettak-voice) installs standalone — it does not touch a netTAK mesh/AP install, and the two can coexist on the same Pi or run on separate boxes.

New to Linux / the Raspberry Pi? Follow the steps exactly in order. Every command is complete — copy and paste each line as-is. The only things you change are the values in <angle brackets>.

1. What you need

  • A Raspberry Pi with a Raspberry Pi Codec Zero HAT, running Raspberry Pi OS 64-bit (Bookworm).
  • The Pi connected to your network (Ethernet recommended) and its IP address.
  • The Pi's login (username + password).
  • A PTT input wired to a GPIO line (default: GPIO 27, active-low) and a mic + speaker on the Codec Zero (line/AUX out).
  • The netTAK voice install bundle: nettak-voice-install-*-arm64.tar.gz (from the netTAK download page). It is fully offline — the GStreamer/Opus/gpiod packages are vendored inside; no apt download is needed on the Pi.
  • ATAK with the VX voice plugin on the handsets you want to talk to.

2. Copy the bundle onto the Pi

From your computer (replace <user> and <pi-ip>):

scp ~/Downloads/nettak-voice-install-*-arm64.tar.gz <user>@<pi-ip>:~/

(Windows: use WinSCP to drag the file into the Pi's home folder.)

3. Install (on the Pi)

Open a session on the Pi (ssh <user>@<pi-ip>), then:

cd ~
tar xzf nettak-voice-install-*-arm64.tar.gz
cd nettak-voice-install-*-arm64
sudo bash scripts/voice/install-voice.sh

The installer:

  • runs a GPL-plugin guard over the vendored debs, then installs them offline,
  • installs the nettak-voice binary to /opt/nettak-voice/bin/,
  • installs the known-good Codec Zero mixer profile (restored on every start),
  • collects license notices under /opt/nettak-voice/licenses/,
  • installs and enables + starts nettak-voice.service.

It preserves an existing /etc/nettak-voice/config, so re-running it to upgrade keeps your settings. (Re-installing over a running service does not auto-restart it — run sudo systemctl restart nettak-voice to activate the new binary.)

4. Configure

Engine settings — /etc/nettak-voice/config

Static, box-local settings (audio device, PTT line, mic/speaker levels). The defaults suit a standard Codec Zero + GPIO-27 PTT. Common keys (uncomment to override):

VOICE_ALSA_DEVICE=plughw:CARD=Zero
VOICE_PTT_LINE=27
VOICE_PTT_ACTIVE_LOW=true

Channels — /etc/nettak-voice/voice.json

The channel table (name → multicast group + port) and this box's active channel. On a netTAK mesh node this file is written and gossiped automatically. On a standalone voice box, place one manually, e.g.:

{
  "channels": [
    { "slot": 1, "name": "Alpha", "group": "239.9.9.9",  "port": 6100 },
    { "slot": 2, "name": "Bravo", "group": "239.9.9.10", "port": 6200 }
  ],
  "active_slot": 2
}

A channel change (edit + sudo systemctl reload nettak-voice, or via the netTAK UI) retunes live — no restart, no dropped audio.

Set your VX (ATAK) endpoints to the same group and port as the active channel to talk to this box.

5. Verify

systemctl is-active nettak-voice          # -> active
cat /run/nettak-voice/status.json         # the engine's self-test

A healthy engine reports (give it ~30 s after a restart to settle):

{"rx_up":true,"tx_up":true,"rx_joined_all_ifaces":true,
 "playback_open":true,"capture_open":true,"restarts_recent":0, ...}
  • rx_up / tx_up — the receive and transmit pipelines are running.
  • rx_joined_all_ifaces — multicast is joined on every IP interface (voice reaches peers on any network segment the box is on).
  • playback_open / capture_open — the Codec Zero speaker and mic are open.

On a netTAK node, the admin Dashboard shows a Voice health chip driven by this same self-test (green / red-with-fault-name / stale). Then press the PTT and confirm two-way audio with a VX handset on the active channel.

6. Update / uninstall

  • Update: copy the newer bundle over and re-run sudo bash scripts/voice/install-voice.sh, then sudo systemctl restart nettak-voice. Config and channels are preserved.
  • Stop / disable: sudo systemctl disable --now nettak-voice.
