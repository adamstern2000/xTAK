netTAK
Install Guide.

← netTAK product Your downloads →

netTAK turns a Raspberry Pi into a self-contained, infrastructure-free TAK network: a Wi-Fi access point your ATAK/WinTAK devices connect to, an optional long-range HaLow mesh linking multiple nodes with no cell or internet, local DNS/DHCP, and a GPS-disciplined clock. Everything is managed from a built-in web admin UI.

This guide covers installing netTAK from the downloaded bundle.

1. Choose your mode

  • Standalone — a single node: Wi-Fi AP + DHCP + local DNS. No extra radio needed. Free.
  • Mesh — two or more nodes linked over HaLow (802.11ah sub-GHz) into one network. Requires a Morse Micro HaLow USB radio on each node. Mesh is a licensed feature (30-day trial included; see Licensing).

2. What you need

  • Raspberry Pi 4B (arm64) with a microSD card running Raspberry Pi OS 64-bit (Bookworm).
  • A wired Ethernet connection to the Pi for the install (you run the installer over the wired port, not over Wi-Fi).
  • For mesh: a Morse Micro HaLow USB radio on each node, plus the netTAK HaLow radio bundle (a separate download — see below).
  • Optional: a serial GPS receiver (e.g. u-blox M10 on the GPIO UART) for precise, offline time. GPS setup is on by default; pass --nogps if you have none.

3. Download and verify

Download the netTAK install bundle and its checksum from the release page, then verify the download before installing:

sha256sum -c SHA256SUMS-<version>.txt
#   nettak-install-<version>-arm64.tar.gz: OK

If verification fails, re-download — do not install a corrupted bundle.

Mesh only: you also need the HaLow radio bundle (halow-radio-<kernel>-arm64.tar.gz). Standalone nodes skip it.

4. Install

Run everything over the wired Ethernet port (not the Wi-Fi AP or mesh) — the installer reconfigures the network and would cut a Wi-Fi session mid-install. SSH to the Pi's wired IP, then:

Standalone node

tar xzf nettak-install-<version>-arm64.tar.gz
sudo ./nettak-install-<version>-arm64/install.sh <hostname> --mode=standalone
sudo reboot

Mesh node

First, install the HaLow radio (once per node):

tar xzf halow-radio-<kernel>-arm64.tar.gz
sudo ./halow-radio-<kernel>-arm64/install-halow-radio.sh
sudo reboot

After reboot the HaLow radio is active. Then install netTAK.

First node in a new mesh (founder):

tar xzf nettak-install-<version>-arm64.tar.gz
sudo ./nettak-install-<version>-arm64/install.sh <hostname>
sudo reboot

With the HaLow radio present, the installer auto-selects mesh mode.

  • Joining an existing mesh: on a node already in the mesh, create a join seed from the web admin (Services → Cluster-join package), copy the resulting seed.json next to the installer on the new node, then install as above. The seed carries the mesh identity, key, and AP settings — the new node joins automatically.

Useful install flags

Flag Purpose
--mode=standalone / --mode=mesh Force the mode (otherwise auto-detected from the HaLow radio).
--ap-ssid=<name> Wi-Fi network name. Default: your hostname with any trailing number removed, so a fleet shares one SSID for seamless roaming.
--ap-password=<pw> Wi-Fi passphrase (≥ 8 chars). Default: password — change it after install.
--mesh-ssid=<name> Mesh network id. Use the same value on every founder to form one fleet mesh.
--nogps Skip GPS setup (use when the node has no GPS receiver).

Choose a hostname ending in a number (e.g. node01, node02) — each node's address is derived from it (node21 → 10.1.21.1).

5. First boot and access

After the reboot, the node broadcasts its Wi-Fi AP (and, on mesh nodes, joins the mesh). Open the admin UI:

  • https://<node-ip>:5103/, or from a device on the AP, https://<hostname>.xtak.ai:5103/

The first-boot certificate is self-signed, so your browser warns once — accept it to continue.

Log in and change the defaults immediately:

  • Admin login: username admin, password password → change it on Admin & security.
  • Wi-Fi AP: default passphrase password → change it on AP.

The built-in operator manual is available in the UI at /help and documents every page and setting.

6. Licensing

  • Standalone operation is free — no license needed.
  • Mesh operation includes a 30-day trial. After the trial, mesh is disabled until you install a license (standalone keeps working).
  • To license a node, open Licensing in the admin UI and either paste a license token (XTAKL1…) issued for the node's hardware, or enter a certificate code from your purchase and Redeem online. Licenses are hardware-tied and verified offline — no internet needed in the field.

7. Verify the install

  • The admin UI loads at https://<node>:5103/ and the Dashboard shows the node online.
  • The Wi-Fi AP is broadcasting and a client can connect and get an address.
  • Mesh nodes: the Dashboard → Mesh card shows neighbor node(s), and you can reach another node's address.
  • Time: the Dashboard Timing card shows a clock source (GPS when a receiver has sky view, otherwise the mesh floor).

For deeper troubleshooting, see the in-UI manual at /help (Troubleshooting section).

8. Uninstall / update

  • Update: re-run install.sh with the same hostname — it updates the binary, configs, and packages in place, preserving your settings.
  • Uninstall netTAK (keeps the HaLow radio): run the bundle's uninstall.sh.
